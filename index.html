면접 예상 질문 생성기

희망 기업·직무와 자기소개서 문항·답변을 입력하면, 답변 내용을 근거로 4가지 유형의 예상 면접 질문을 만들어드려요. 마음에 드는 질문을 최대 3개 골라 워크시트에 옮겨 적어보세요.

0API 키 설정 (최초 1회, 브라우저에서 직접 열었을 때만 필요)

이 페이지를 Claude.ai 밖(다운로드한 파일, 학교 웹페이지, QR 접속 등)에서 열었다면 본인의 Anthropic API 키가 있어야 질문 생성이 작동합니다. 아래 순서로 발급받으세요.

  1. console.anthropic.com에 접속해 로그인(또는 회원가입)합니다.
  2. 좌측 메뉴의 API Keys로 이동합니다.
  3. Create Key를 눌러 이름을 정하고 키를 생성합니다.
  4. 생성된 키(sk-ant-... 형태)를 복사해 아래 입력창에 붙여넣습니다.

※ API는 사용량 기반 유료 서비스입니다. console.anthropic.com의 Billing 메뉴에서 결제수단 등록이 필요할 수 있습니다. 키는 이 브라우저 탭에만 임시로 저장되며, 새로고침하면 다시 입력해야 합니다.
